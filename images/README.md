# Folder Foto Barang

Taruh foto barang di sini, misalnya `images/00000001.jpg`.
Website otomatis memuat foto yang path-nya di field **Foto** pada form item.

Cara termudah: drag & drop foto ke GitHub lewat web UI repo, atau commit lokal.
Nama file bebas, tapi disarankan pakai ID item (8 hex) agar mudah dicocokkan.

Contoh isi field Foto item: `images/00000001.jpg`
